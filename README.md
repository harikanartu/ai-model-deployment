Full-Stack Generative AI Application

Developed and deployed a full-stack AI-powered text generation platform that uses Google Gemini to generate intelligent, context-aware responses to user prompts. Built a responsive React frontend and a Python FastAPI backend, integrated through REST APIs, and deployed the frontend on Vercel and backend on Render.

Key Features

Interactive AI interface with prompt submission and formatted responses.

RESTful API development using FastAPI and Pydantic request validation.

Integration with Google Gemini API for LLM-powered text generation.

Cross-origin communication between frontend and backend using CORS.

Secure API key management through environment variables.

GitHub-based version control and deployment workflow.

Tech Stack: Python, FastAPI, React, JavaScript, Google Gemini API, REST APIs, Pydantic, HTML, CSS, Git, GitHub, Render, Vercel.
